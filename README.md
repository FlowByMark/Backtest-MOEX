# Backtest MOEX — исследование снятия ликвидности Si

Локальное аналитическое приложение для ручного бэктеста поведения фьючерса Si после открытия основной сессии Московской биржи в 10:00.

Приложение загружает официальные минутные свечи MOEX ISS, собирает графики M5/M15 и помогает размечать снятие выбранного экстремума без попытки заранее угадать направление цены.

## Что исследуется

Рабочая гипотеза: около открытия рынок снимает ближайший значимый M5/M15-экстремум, затем может вернуться за уровень и пойти в противоположную сторону.

Пользователь вручную выбирает:

1. HIGH или LOW и свечу, сформировавшую уровень до 10:00.
2. Свечу первого снятия уровня.
3. Исход наблюдения:
   - **ТЕЙК / без пересвипа** — после подтверждённого возврата стоп-уровень не пересекался повторно до 18:50;
   - **СТОП / пересвип** — цена повторно пересекла экстремум исходной M5-свечи снятия;
   - **Нет входа в день** — подходящего сетапа по модели не было.

Это исследовательский инструмент, а не торговый сигнал и не инвестиционная рекомендация.

## Возможности

- графики M5 и M15 за полную торговую сессию;
- ручной выбор HIGH/LOW, первого снятия и пересвипа;
- автоматический контроль стоп-уровня по M5-свече снятия;
- сохранение разметки на диск и восстановление отметок на графике;
- отметка просмотренных дней без входа;
- статистика по месяцам и общей выборке;
- средний, медианный, P75, P90 и максимальный прокол;
- максимальный доступный ход после возврата за 15/30/60 минут и до 18:50;
- средний и медианный результат через 15/30/60 минут;
- доля положительных результатов через 15/30/60 минут и к 17:00;
- количество тейков, стопов, дней без входа и случаев без назначенного исхода;
- экспорт/импорт разметки CSV и переносимый ZIP проекта.

## Запуск в Windows

1. Установите Python 3.12 или новее.
2. Скачайте исходники репозитория в одну папку.
3. Запустите `START_WINDOWS.bat`.
4. Дождитесь загрузки данных MOEX и открытия браузера.
5. Не закрывайте окно командной строки во время работы — через него разметка сохраняется в файл.

Внешние Python-библиотеки не требуются: приложение использует стандартную библиотеку Python.

## Где хранятся данные

- `Si_research_data.json` — основная сохранённая разметка;
- `Si_research_data.json.bak` — предыдущая резервная копия;
- `_si_moex_cache/` — локальный кэш свечей MOEX;
- `Si_open_2026_5m.html` — сгенерированное приложение с графиком.

Эти файлы исключены из GitHub через `.gitignore`, поэтому личные результаты исследования не публикуются вместе с исходным кодом.

Кнопка **«Экспорт проекта ZIP»** создаёт переносимую копию с исходниками, текущей разметкой и готовым HTML. Такой архив можно перенести на другой компьютер или передать другому человеку.

## Важные определения

### Прокол

Максимальное расстояние за выбранный уровень до подтверждённого закрытием M5 возврата. Для входа непосредственно от уровня это неблагоприятное движение.

### Возврат

Первое закрытие M5 обратно за выбранным уровнем: ниже HIGH либо выше LOW.

### Стоп-уровень

Экстремум исходной M5-свечи первого снятия: high для снятия HIGH и low для снятия LOW.

### Пересвип / стоп

Повторное пересечение стоп-уровня после подтверждённого возврата. Максимальный ход до стопа рассчитывается только по полностью завершённым M5-свечам перед свечой пересвипа, поскольку порядок high и low внутри одной свечи неизвестен.

### Тейк

Пока это не фиксированная цель в пунктах. Метка означает объективный исход **«пересвипа не было до 18:50»**. Накопленные данные о максимальном ходе позволят позже проверить разные цели в пунктах или в `R` без переоценки исходных графиков.
